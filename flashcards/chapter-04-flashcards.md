## Chapter 4: Azure Infrastructure Security and Microsoft Defender for Cloud — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Azure DDoS Protection Basic vs Network Protection (Standard) — key difference? | Basic: free, automatic, always-on, platform-level mitigation, no SLA. Network Protection: paid, adds SLA guarantee, cost protection for attack-related scale-out, DDoS Rapid Response support team access. Exam tip: 'cost protection' and 'rapid response' = Network Protection. |
| 2 | NSG vs Azure Firewall vs WAF — which layer does each operate at? | NSG: Layer 3/4 (IP, port, protocol). Azure Firewall: up to Layer 7, network/application filtering + FQDN + threat intel. WAF: Layer 7, HTTP/HTTPS only, blocks OWASP Top 10 exploits (SQLi, XSS). |
| 3 | Which service blocks SQL injection and cross-site scripting attacks on a web app? | Web Application Firewall (WAF), deployed with Application Gateway, Front Door, or CDN. Exam tip: WAF is application-layer specific — NSGs and Firewall cannot inspect HTTP payloads. |
| 4 | Minimum subnet size and required name for Azure Bastion deployment? | /26 minimum, subnet must be named exactly 'AzureBastionSubnet'. Exam tip: naming is case-sensitive and mandatory, similar to GatewaySubnet for VPN gateways. |
| 5 | What does Azure Bastion eliminate the need for on target VMs? | A public IP address and open RDP (3389)/SSH (22) ports directly on the VM. Connectivity is via the Azure portal over TLS 443. Exam tip: Bastion = secure browser-based RDP/SSH, no public IP exposure. |
| 6 | How is Microsoft Defender for Cloud's secure score calculated? | Percentage = (completed recommendation points) / (maximum possible points) across applicable resources. Exam tip: enabling a Defender plan alone doesn't raise the score — remediating recommendations does. |
| 7 | What is Cloud Security Posture Management (CSPM)? | Continuous automated assessment of cloud resource configurations against security best practices, surfacing misconfigurations and recommendations. Defender for Cloud's Foundational CSPM is free; Defender CSPM plan (paid) adds attack path analysis and agentless scanning. |
| 8 | What does the Regulatory Compliance dashboard in Defender for Cloud show? | Compliance status against standards like PCI-DSS, ISO 27001, SOC 2, NIST, mapped to the Microsoft Cloud Security Benchmark (MCSB) as the default baseline. Exam tip: it's built on top of secure score recommendations mapped to compliance controls. |
| 9 | Which firewall service supports FQDN-based outbound filtering and threat intelligence across multiple VNets/subscriptions? | Azure Firewall, managed centrally via Azure Firewall Manager. Exam tip: NSGs cannot filter by FQDN — only by IP/port. |
| 10 | What is network segmentation used for in Azure security architecture? | Dividing a network into isolated zones (e.g., hub-spoke topology) to limit lateral movement of attackers and enforce granular traffic control between tiers/workloads using NSGs, Firewall, and route tables. |
| 11 | Is NSG usage billed separately in Azure? | No — NSGs are included at no additional cost. Exam tip: contrast with Azure Firewall and WAF, which are paid services billed based on deployment/throughput. |
| 12 | Scenario rule: mission-critical app needing SLA + cost protection from DDoS attacks — which tier? | Azure DDoS Protection Standard (Network Protection). Basic has no SLA or cost protection. Exam tip: keywords 'SLA', 'cost protection', 'Rapid Response' always point to Network Protection, not Basic. |
