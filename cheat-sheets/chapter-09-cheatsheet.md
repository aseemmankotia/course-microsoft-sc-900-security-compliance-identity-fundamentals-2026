# SC-900 Practice Exam & Time-Management Cheat Sheet

## Domain Weight Reference (verify current values on Microsoft Learn)
| Domain | Approx. Weight |
|---|---|
| Concepts of security, compliance, identity | 10-15% |
| Microsoft Entra capabilities | 25-30% |
| Microsoft security solutions | 35-40% |
| Microsoft compliance solutions | 20-25% |

⚠️ Exam domains and weights change periodically — always re-check the 'Skills measured' tab on the official Microsoft Learn exam page before test day.

## Time Budget
| Exam Length | Target Pace |
|---|---|
| 45-60 minutes | ~1 min/question average |
| Unsure question | Eliminate 2 options → flag → guess → move on |
| Final 5-10 min | Return to flagged questions only |

## Question Types on Fundamentals Exams
| Type | Strategy |
|---|---|
| Multiple-choice (1 answer) | Eliminate implausible distractors first |
| Multiple-response (select N) | Judge each option true/false independently |
| Drag-and-drop / matching | Match the most confident pairs first, then infer remaining by elimination |

## Elimination Technique
1. Cross out options referencing deprecated or wrong-category services.
2. Cross out options that satisfy only part of the requirement.
3. Compare remaining options against every constraint in the scenario.
4. Choose the option that is BOTH correct AND most complete.

## Pre-Exam Weak-Domain Review Routine
1. Take a full timed practice exam.
2. Score results by domain, not just overall.
3. Rank domains lowest → highest score.
4. Spend remaining study time proportionally more on the lowest-scoring domain(s).
5. Re-test only that domain's questions 24-48 hours before the real exam.

## Final Reminders
- Confirm exam registration details, duration, and passing score directly on Microsoft Learn before test day — these are periodically updated by Microsoft.
- Never leave a question blank; an educated guess after elimination beats zero credit.
- Flag-and-return only if time remains after a full first pass.
