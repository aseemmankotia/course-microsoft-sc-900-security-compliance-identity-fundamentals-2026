## Chapter 7: Microsoft Purview: Compliance Foundations and Data Protection — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Sensitivity labels vs DLP policies — core difference? | Sensitivity labels CLASSIFY and PROTECT content (encrypt, mark, restrict) and persist with the file. DLP policies DETECT sensitive info and ENFORCE actions (block, warn, notify) to prevent leakage. Exam tip: labels = protect the content itself; DLP = prevent the action of leaking it. |
| 2 | Content explorer vs Activity explorer | Content explorer = current snapshot of where classified/labeled content exists right now. Activity explorer = historical log of user actions on labeled content (label applied, changed, removed) over time. |
| 3 | Sensitive Information Type (SIT) vs Trainable Classifier | SIT = pattern-based detection (regex, keyword, checksum) for structured data like SSNs, credit cards. Trainable classifier = ML-based, trained on sample documents, used for unstructured/contextual content (e.g., resumes, harassment complaints) that lacks a fixed pattern. |
| 4 | What does Compliance Manager's compliance score represent? | A measurable indicator of your progress completing recommended improvement actions mapped to regulatory/standard assessments. It is NOT a fixed universal number — it's tenant- and assessment-specific. |
| 5 | Compliance Manager improvement action categories | Actions are categorized as Preventive, Detective, or Corrective, and as Mandatory or Discretionary. Controls are also grouped as Microsoft-managed, Customer-managed, or Shared. |
| 6 | SIT confidence levels | Sensitive Information Types report matches with Low, Medium, or High confidence based on how well surrounding evidence (keywords, checksum, proximity) supports the pattern match. Exam tip: higher confidence = more supporting evidence found near the match. |
| 7 | Trainable classifier — minimum seed content | Microsoft recommends starting with a minimum of about 50 sample (seed) items of the content type to train a classifier, using both positive and negative examples for better accuracy. |
| 8 | Sensitivity label priority order | Labels are ordered from least to most restrictive in the label list. When multiple labels could auto-apply, the label positioned LOWER (higher priority number) in the list wins. |
| 9 | What can a sensitivity label do to a document/email? | Apply encryption, add content marking (headers/footers/watermarks), restrict permissions/access, and be used for container labels on Teams/SharePoint sites/groups. Can also be applied automatically via auto-labeling policies. |
| 10 | Regulatory templates in Compliance Manager | Pre-built templates (e.g., GDPR, ISO 27001, NIST 800-53) used to create assessments with pre-mapped controls and recommended improvement actions for a specific regulation or standard. |
| 11 | DLP policy locations (common exam list) | DLP policies can apply to Exchange Online, SharePoint Online, OneDrive, Teams chat/channel messages, Windows/macOS endpoint devices, on-premises repositories (via scanner), Power BI, and third-party cloud apps (via Defender for Cloud Apps). |
| 12 | Microsoft Purview compliance portal — former name? | Formerly Microsoft 365 compliance center (compliance.microsoft.com). Exam tip: SC-900 may reference the old name in scenario wording — treat it as the same portal now branded as Microsoft Purview compliance portal. |
