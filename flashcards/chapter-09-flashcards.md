## Chapter 9: Full SC-900 Practice Exam and Time-Management Strategy — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | SC-900 exam: four domains — which one typically carries the HEAVIEST weight? | Describe the capabilities of Microsoft security solutions (~35-40%). Exam tip: allocate proportional review time — don't spend equal time on all four domains. Always confirm current weights on Microsoft Learn before scheduling. |
| 2 | Roughly how much time should you budget per question on a 45-60 minute fundamentals exam? | ~1 minute per question as a baseline. Flag anything taking longer, guess-and-move-on, return during review if time remains. |
| 3 | Elimination strategy for a 4-option multiple-choice question you don't know | 1) Remove options referencing deprecated/wrong-category services. 2) Remove options that only partially meet requirements. 3) Pick the most complete match from what's left. Never leave it blank. |
| 4 | Conditional Access vs. Identity Protection — key difference? | Conditional Access = policy ENFORCEMENT engine (if signal X, require action Y). Identity Protection = risk DETECTION engine (flags risky sign-ins/users) that feeds signals into Conditional Access. |
| 5 | Three Zero Trust guiding principles (Microsoft model) | 1) Verify explicitly 2) Use least privileged access 3) Assume breach. Exam tip: match scenario keywords — 'segment/limit blast radius' = assume breach; 'only access needed' = least privilege. |
| 6 | Defender for Cloud vs. Defender for Endpoint vs. Defender for Office 365 | Defender for Cloud = posture/Secure Score for Azure/hybrid/multicloud resources. Defender for Endpoint = device/EDR threat protection. Defender for Office 365 = email/collaboration phishing & malware protection. |
| 7 | Purview Compliance Manager — what does its score represent? | A percentage-based measurement of progress toward completing recommended actions across regulatory/standard assessments. Exam tip: it's about compliance posture, not Azure resource security (that's Secure Score). |
| 8 | Sensitivity labels vs. retention labels — exam distinction | Sensitivity labels = classify & PROTECT content (encryption, watermark, access restriction). Retention labels = govern how long content is KEPT or when it's deleted, for records/compliance. |
| 9 | Continuous Access Evaluation (CAE) — what problem does it solve? | Near real-time revocation of access tokens when critical events occur (user disabled, password changed, device marked lost) instead of waiting for token expiry. Works alongside Conditional Access. |
| 10 | Practice-exam review strategy: what to do with your WEAKEST domain score before test day | Prioritize remaining study time there — the domain contributing most to a failing composite score gives the highest return on additional review, regardless of its exam weight percentage. |
| 11 | Before scheduling/taking SC-900, what should you always verify on Microsoft Learn? | The current 'Skills measured' PDF/page — domain names, weight percentages, and in-scope services change periodically as Microsoft updates the exam. |
| 12 | Multi-response question strategy (e.g., 'Select all that apply') | Evaluate EACH option independently as true/false rather than comparing options against each other; partial credit is typically NOT given, so verify every selected option before moving on. |
